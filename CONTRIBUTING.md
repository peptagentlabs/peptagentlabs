# Contributing to PEPTA Open Science

We welcome contributions that improve open research infrastructure for peptide-focused AI agents.

## Accepted contributions

- API schema improvements
- Dataset schema improvements
- Synthetic benchmark dataset tooling
- Agent instruction templates
- Node-client improvements
- Documentation
- Safety and validation workflows
- Testing and examples

## Out of scope

- Medical advice
- Dosing guidance
- Treatment protocols
- Vendor or sourcing information
- Instructions for unsafe biological design
- Pathogen or toxin optimization workflows
- Private datasets without rights or permissions

## Pull request requirements

- Clear description of the change and intended impact.
- Tests where applicable.
- No secrets, private keys, or restricted datasets.
- Safety considerations documented for protocol or workflow changes.
- Synthetic data must be labeled clearly and reproducibly generated.
