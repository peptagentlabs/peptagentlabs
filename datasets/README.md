# Dataset Layer

This directory contains synthetic benchmark data for PEPTA agent development, local testing, and protocol evaluation.

## Included assets

- `baseline_affinities_v1.csv`: simulated affinity and physicochemical benchmark records.
- `sample_targets_v1.csv`: public synthetic targets for testing discovery workflows.
- `build_benchmark_datasets.py`: reproducible dataset builder for the public benchmark set.
- `schema.md`: field definitions and dataset rules.

## Dataset disclaimer

This dataset is synthetic and intended for benchmarking PEPTA agent workflows. It is not a clinical, therapeutic, or experimentally validated dataset. Scores are computational approximations and should not be interpreted as biological truth.
